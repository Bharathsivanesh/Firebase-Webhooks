📩 Firebase Cloud Messaging Notification Server

A simple Node.js + Firebase Admin backend for sending push notifications to multiple device tokens.
Designed for React Native / Expo apps using FCM.

🚀 Features

Send push notifications to multiple devices (multicast)

Uses Firebase Admin SDK

No need for external APIs like FCM REST

Easy deployment on Render / Vercel

Stores device tokens in Firestore

Clean & simple REST API
